# 포켓몬 데스크톱 펫

바탕화면 위를 돌아다니는 포켓몬 데스크톱 펫입니다. 몬스터볼로 포켓몬을 포획하고, 기르고, 전체 플레이어와 리더보드에서 경쟁할 수 있습니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/gitforyoung/poketmonpet/releases/latest)** — Releases 페이지에서 `PokemonPet-x.x.x.zip`을 받아 압축을 풀고 `.exe` 파일을 실행하면 됩니다. 별도 설치 과정은 없습니다.

Windows 10/11 전용이며, 실행 시 "Windows의 PC 보호"(SmartScreen) 경고가 뜰 수 있습니다. 서명되지 않은 개인 배포 프로그램이라 뜨는 정상적인 경고이니, **추가 정보 → 실행**을 눌러주세요.


- **포획**: 몬스터볼/슈퍼볼/하이퍼볼/마스터볼 4종류. 등급이 높은 볼일수록 희귀한 포켓몬이 더 잘 나오고 포획 확률도 높습니다.
- **육성**: 활성 몬스터는 시간에 따라, 그리고 야생 몬스터와의 자동 배틀을 통해 경험치를 얻고 레벨업합니다.
- **이로치(샤이니)**: 아주 낮은 확률로 색이 다른 개체가 등장합니다.
- **도감**: 잡아본 모든 종이 기록되며, 일정 종수를 채우면 마스터볼을 보상으로 받습니다. 마스터볼은 앱을 오래 켜둘수록(누적 실행 시간 기준)도 받을 수 있습니다.
- **클라우드 저장**: 기기를 바꾸거나 앱을 재설치해도 진행 상황이 유지됩니다. 복구 코드로 다른 PC에서 이어할 수 있습니다.
- **리더보드**: 닉네임을 등록하면 도감 진척도·최고 레벨·이로치 보유 수 등 여러 항목에서 다른 플레이어와 순위를 겨룰 수 있습니다. → **[리더보드 보기](https://poketmonpet.vercel.app)** (하루 3번 갱신)

## 계정 및 데이터

- 별도 회원가입 없이 실행 즉시 익명 계정이 자동으로 생성됩니다.
- 트레이 메뉴의 "복구 코드 발급/재발급"으로 다른 기기에 저장 데이터를 옮길 수 있습니다.
- 리더보드에 표시되는 닉네임은 자동으로 `PlayerNNNN` 형태로 부여되며, 트레이 메뉴 "닉네임 설정"에서 언제든 원하는 이름으로 바꿀 수 있습니다.
