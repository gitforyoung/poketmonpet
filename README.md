# 포켓몬 데스크톱 펫

바탕화면 위를 돌아다니는 포켓몬 데스크톱 펫입니다. 몬스터볼로 포켓몬을 포획하고, 기르고, 전체 플레이어와 리더보드에서 경쟁할 수 있습니다.

## 다운로드

**[최신 버전 다운로드](https://github.com/gitforyoung/poketmonpet/releases/latest)** — Releases 페이지에서 `PokemonPet-x.x.x.zip`을 받아 압축을 풀고 `.exe` 파일을 실행하면 됩니다. 별도 설치 과정은 없습니다.

Windows 10/11 전용이며, 실행 시 "Windows의 PC 보호"(SmartScreen) 경고가 뜰 수 있습니다. 서명되지 않은 개인 배포 프로그램이라 뜨는 정상적인 경고이니, **추가 정보 → 실행**을 눌러주세요.

## 주요 기능

- **포획**: 몬스터볼/슈퍼볼/하이퍼볼/마스터볼 4종류. 등급이 높은 볼일수록 희귀한 포켓몬이 더 잘 나오고 포획 확률도 높습니다.
- **육성**: 활성 몬스터는 시간에 따라, 그리고 야생 몬스터와의 자동 배틀을 통해 경험치를 얻고 레벨업합니다.
- **이로치(샤이니)**: 아주 낮은 확률로 색이 다른 개체가 등장합니다.
- **클라우드 저장**: 기기를 바꾸거나 앱을 재설치해도 진행 상황이 유지됩니다.
- **리더보드**: 닉네임을 등록하면 여러 항목에서 다른 플레이어와 순위를 겨룰 수 있습니다. → **[리더보드 보기](https://poketmonpet.vercel.app)** (하루 3번 갱신)

## 게임 플레이 방법

실행하면 화면 위에 포켓몬 한 마리(처음엔 피카츄)가 나타나 자유롭게 돌아다닙니다. 모든 조작은 화면 오른쪽 아래 **시스템 트레이 아이콘**을 우클릭해서 뜨는 메뉴로 이루어집니다.

### 포켓몬 포획하기

트레이 메뉴 **"몬스터볼 던지기"**에서 볼 종류를 고르면, 볼이 포물선을 그리며 떨어지고 바운스합니다. 볼이 착지하면 그 옆에 야생 포켓몬이 나타나고, 볼이 튀어 올라 포켓몬을 흡수하려 시도합니다.

- **성공**: 파티클 효과와 함께 "OOO을(를) 잡았다!" 문구가 뜨고, **보관**할지 **놓아줄지** 선택하는 창이 나타납니다. 보관하면 보관함에 새 개체로 추가되고, 놓아줘도 도감엔 그 종이 기록됩니다.
- **실패**: 포켓몬이 옆으로 재빠르게 튕겨 달아나며 사라집니다. 볼만 소모됩니다.

볼 종류별로 포획 확률과 함께 **희귀한 포켓몬이 등장할 확률 자체**도 달라집니다 — 등급이 높은 볼일수록(마스터볼이 가장 강력) 희귀·전설급 포켓몬을 만날 가능성이 크게 올라갑니다.

### 몬스터볼 얻는 법

| 볼 | 시작 보유 | 자동 충전 | 그 외 획득 경로 |
|---|---|---|---|
| 몬스터볼 | 5개 | 30분마다 +1 (최대 10개) | - |
| 슈퍼볼 | 2개 | 3시간마다 +1 (최대 5개) | - |
| 하이퍼볼 | 1개 | 24시간마다 +1 (최대 2개) | - |
| 마스터볼 | 1개 | 자동 충전 없음 | 도감에 새 종 25종마다 +1<br>누적 실행 시간 8시간마다 +1 |

### 보관함 관리

트레이 메뉴 **"보관함"**에서 지금까지 잡은 포켓몬 목록을 볼 수 있습니다.

- 목록을 클릭하면 그 포켓몬이 화면의 활성 몬스터로 바뀝니다 (보관함에 있는 것만 성장 대상이 됩니다).
- **"이름바꾸기"**로 개체별 별명을 지을 수 있습니다 (중복 가능).
- **"놓아주기"**로 슬롯을 비울 수 있습니다 (단, 마지막 한 마리는 놓아줄 수 없습니다).
- 마우스를 올리면 레벨/성격/개체값 등 상세 스탯을 툴팁으로 볼 수 있습니다.

### 성장과 배틀

화면의 활성 몬스터는 앱을 켜놓은 시간에 비례해 자동으로 경험치를 얻고, 이따금 야생 포켓몬과 마주쳐 자동으로 서로 공격을 주고받는 배틀을 벌입니다(이기면 더 많은 경험치). 포켓몬을 직접 클릭해도 소량의 경험치를 얻습니다.

### 도감과 이로치

포획을 시도해 등장한 모든 종은 도감(트레이 메뉴 **"도감"**)에 기록됩니다. 아주 낮은 확률로 색이 다른 **이로치** 개체가 등장하며, 보관함에서 ✨ 표시로 구분됩니다.

### 리더보드 참여

처음 클라우드에 연결되면 `PlayerNNNN` 형태의 닉네임이 자동으로 부여되어 곧바로 순위에 집계됩니다. 트레이 메뉴 **"닉네임 설정 (리더보드)"**에서 원하는 이름으로 언제든 바꿀 수 있습니다. 순위는 [리더보드 사이트](https://poketmonpet.vercel.app)에서 하루 3번 갱신됩니다.

## 계정 및 데이터

- 별도 회원가입 없이 실행 즉시 익명 계정이 자동으로 생성됩니다.
- 트레이 메뉴의 "복구 코드 발급/재발급"으로 다른 기기에 저장 데이터를 옮길 수 있습니다.
